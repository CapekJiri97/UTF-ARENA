1. Neshoda v názvech proměnných (Zásadní bug)
V CLASSES definuješ základní poškození jako baseAD a baseAP. Ale v pomocné funkci voláš pl.baseAD_stat:

JavaScript
export const addAdaptive = (pl, pct) => {
  if (pl.dmgType === 'magical') pl.AP = (pl.AP || 0) + Math.round((pl.baseAP_stat || 0) * pct);
  // ...
Jak to opravit:
Buď v konstruktoru tvého Player.js při vytváření hrdiny musíš udělat:
this.baseAP_stat = CLASSES[this.className].baseAP;
Nebo tu pomocnou funkci jednoduše přepiš, aby brala přímo tu správnou proměnnou z CLASSES:

JavaScript
export const addAdaptive = (pl, pct) => {
  const baseAP = CLASSES[pl.className]?.baseAP || 0;
  const baseAD = CLASSES[pl.className]?.baseAD || 0;
  
  if (pl.dmgType === 'magical') pl.AP = (pl.AP || 0) + Math.round(baseAP * pct);
  else pl.AD = (pl.AD || 0) + Math.round(baseAD * pct);
};
2. Pořád ti chybí unique: true!
Ve funkci canBuyShopItem tu kontrolu máš připravenou skvěle (if (item.unique && ...)). Jenže v poli shopItems jsi ten flag k itemům nepřidal. To znamená, že item není unikátní a hráč si pořád může poskládat inventář šesti Bloodthirsterů.

Jak to opravit:
Projdi si všechny itemy (nebo alespoň ty Tier 3 finální) a přidej jim tam ten parametr. Například:

JavaScript
{
  id: 'off_t3_ls', name: 'Bloodthirster', desc: '+~50 Power, +30% AS, +10% Lifesteal', cost: 600,
  treeId: 'offense', treeBranch: 'as_branch', requires: 'off_t2_as', unique: true, // <-- TADY
  apply: (pl) => { /* ... */ }
}
3. Zmizely nám boty a rozbijí AI
V minulém bloku jsme pro AI (bota) nastavovali logiku, která začíná tímto:
let boots = shopItems.find(it => it.id === 'boots');
Pokud boti v shopu nenajdou item s ID boots, nakupovací skript se jim zacyklí nebo začne házet errory a boti nevyjdou z fontány.

Jak to opravit:
Přidej na konec shopItems aspoň jedny univerzální boty mimo stromy:

JavaScript
  // ==========================================
  // BOOTS (Core for AI and players)
  // ==========================================
  {
    id: 'boots', name: 'Traveler Boots', desc: '+40 Movement Speed', cost: 300,
    treeId: 'boots', treeBranch: 'core', unique: true,
    apply: (pl) => { pl.speed += 40; }
  }
Jakmile ošetříš tyhle tři věci, tvůj datový základ pro itemy je neprůstřelný. Pak už bude "jen" stačit pohlídat si v Player.js, aby se při nákupu upgradu ten starý item opravdu smazal z inventáře a staty se přepočítaly od nuly, jak jsme řešili.
